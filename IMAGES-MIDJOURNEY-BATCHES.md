# EdenFlats picture batches

Every picture the EdenFlats website still needs: 27 photos, the same for both versions (A, the current one, and B, the template one). Each option inside the braces becomes its own grid of four; keep one picture per grid.

8 prompts, 28 grids, about 22 of 200 Fast minutes (V8.1, Basic plan).

## How to use them

- **Paste up to three prompts**, let them finish, then the next ones. The Basic plan runs 3 grids at once and queues 10.
- **Keep the backslashes.** The \, inside the braces keeps each option in one piece; a plain comma starts the next option.
- **Step 1 first.** Pick the best home-page picture, copy its link, and add --sref followed by that link at the end of every later prompt, so the whole set shares its light and colours.
- **One picture per grid.** Save it under the file name before the colon (accueil-hero.png, paris-marais.png…) and send them to me: I crop them to size and put them on both versions.
